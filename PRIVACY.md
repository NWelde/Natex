# Natex Privacy Policy

Last updated: 2026-11-01

## Overview
Natex is a Chrome extension that lets you write LaTeX with a live preview and insert it into Quill rich text editors on websites you choose to enable.

## Data We Collect
Natex does **not** collect, sell, or share personal data. It has no analytics or tracking.

## Data Stored in Your Browser
Natex stores a small amount of data using Chrome extension storage, only to make the extension work:
- **Allowed sites**: the websites where you enabled Natex, so you don't have to enable it again every time.
- **Your hotkey**: the keyboard shortcut that opens the editor, if you changed it.
- **Drafts**: the text you were writing in the Natex editor, saved per page and text box so it survives closing the editor or reloading the page. Drafts are removed when you insert them or press Discard, and drafts older than 30 days are discarded.

Allowed sites and your hotkey use Chrome's sync storage, so they follow your Chrome profile if you have Chrome sync turned on. Drafts use Chrome's local storage and stay on your device.

You can remove all of this at any time by removing the extension.

## Data Sharing / Transmission
Natex does **not** send your settings, drafts, browsing history, or page content to any server. LaTeX is rendered inside the page you are editing.

## Website Content Access
When enabled on a site, Natex needs access to that site to detect Quill editors, insert formulas, and open existing formulas for editing. It does not read unrelated page content; it works only with the Quill editor elements it needs.

## Remote Code
Natex does not download or execute remote code. All extension logic, including the KaTeX renderer and its fonts, is packaged with the extension.
