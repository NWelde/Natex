# Natex 1.0

Write LaTeX in Quill-based editors with a live preview, customizable hotkeys, and automatically saved drafts.

Natex 1.0 comes as a ready-to-install ZIP. No Node.js, npm, or build commands needed.

## Install

1. Download **natex-1.0.0.zip** from Assets below.
2. Extract it into a folder you will keep on your computer.
3. Open `chrome://extensions` and enable **Developer mode**.
4. Click **Load unpacked** and select the extracted folder containing `manifest.json`.
5. Pin Natex from Chrome's extensions menu.

Use the **fx** button or **Ctrl+M** in a supported Quill editor to open Natex.

Download the Natex ZIP, rather than the automatically generated Source code archives. Keep the extracted folder after installation: Chrome loads the extension from it.
